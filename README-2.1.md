# GLOBAL NEWS24 DIGITAL NEWSROOM v2.1.0

이번 버전은 기존 v2.0 프로토타입을 기반으로 PC·모바일 메뉴 체계와 콘텐츠 생태계를 강화한 통합 개편본입니다.

## 핵심 반영사항
- PC: 상단 고정 풀 메가메뉴, 메뉴별 대형 서브패널
- 모바일: 햄버거에 주요 카테고리를 숨기지 않고 가로 스크롤 메뉴 상시 노출
- 모바일: 메뉴 터치 시 2열 메가메뉴 패널 오픈
- 햄버거: 신문사 소개·편집정책·기사제보·광고·아카이브 등 보조메뉴 전용
- 상단 스티키 내비게이션
- BREAKING 티커
- TOP NEWS 선택적 광택 애니메이션
- BREAKING 카드 점멸 효과
- PICK/주요기사 강조 효과
- 주요뉴스·최신뉴스·주목뉴스·전문 네트워크 섹션
- ACTS·태권검도·경찰무도·드론순찰대·GLOBAL NEWS24 콘텐츠 생태계
- 영상뉴스·포토뉴스·칼럼 영역
- 하단에 버전정보 `v2.1.0` 상시 표시
- 모션 감소 설정(prefers-reduced-motion) 대응

## 운영 방향
활동 → Global News24 기사 → 관련 단체 홈페이지 공유 → 유튜브/SNS 확산 → 아카이브 축적

향후 Supabase 연결 시 기사 작성·검토·승인·발행·관련 단체 자동노출 구조로 확장하도록 설계했습니다.
