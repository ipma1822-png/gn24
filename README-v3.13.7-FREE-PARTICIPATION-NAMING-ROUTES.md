# GLOBAL NEWS24 v3.13.7 — 무료 참여기자 명칭·진입동선 통일

## PHASE 7-8

정식 기자 체계와 무료 참여기자 체계를 홈페이지에서 명확히 분리하고, 기존 `시민리포터 / 청소년리포터 / 어린이기자단` 명칭을 다음 공식 명칭으로 통일했다.

- 시민기자
- 청소년기자
- 어린이기자

## 적용 내용

1. `pages/reporter-recruit/index.html`
   - 정식 기자 지원과 무료 참여 신청을 첫 화면에서 분리
   - 시민기자·청소년기자·어린이기자 명칭 통일
   - `/pages/participant-apply/` 무료 참여 신청 연결
   - `/pages/participant-submit/` 승인 참여자 제보 연결
   - 정식 기자 직급과 무료 참여구분이 별개임을 명시

2. `pages/reporter-policy/index.html`
   - 운영규정 v1.1로 명칭 정리
   - 무료 참여기자 3종 공식 명칭 통일
   - 청소년·어린이 보호자동의 원칙 명시
   - 활동번호가 비밀번호·정식 기자증·공인자격이 아님을 명시
   - 정식 기자와 무료 참여기자의 권한 분리 원칙 명시

3. `pages/admin-reporter-operations/index.html`
   - 본사 기자 운영센터에 무료 참여기자 관리 진입점 추가
   - 정식 기자 통계와 무료 참여기자 관리를 구분

## 유지 원칙

- 정식 기자: 본사 심사 → 위촉 → 기자번호 → 기자증 → 기자 직급 체계
- 무료 참여기자: 무료 신청 → 본사 승인 → 활동번호 → 제보 → 본사 검토
- 무료 참여기자는 정식 기자의 `기자 / 선임기자 / 수석기자` 직급을 자동으로 갖지 않는다.
- 무료 참여기자는 `admin / editor / reporter` 시스템 권한을 자동으로 갖지 않는다.
- 최종 편집권과 발행권은 본사에 있다.
