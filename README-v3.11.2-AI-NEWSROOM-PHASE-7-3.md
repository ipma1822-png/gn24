# GLOBAL NEWS24 AI NEWSROOM — PHASE 7-3
Version: v3.11.2

## 목표
기자의 현장 동작을 `말하기 → 사진 찍기 → 본사 보내기` 한 화면으로 단순화한다.

## 완료
- 기존 음성취재 화면에 휴대폰 사진 직접 첨부 통합
- 최대 8장, 이미지 1장 10MB 제한
- PHASE 7-2의 reporter-media Storage와 기자별 폴더 정책 재사용
- 음성 텍스트와 사진 URL을 하나의 gn24_reporter_submissions 레코드에 결합
- 전송 전 draft 생성 후 사진 업로드, 성공 후 submitted 전환
- 업로드/전송 실패 시 취재 텍스트가 draft로 남도록 설계
- 기자 손안의 마법사 첫 버튼을 `현장취재 바로 시작`으로 변경
- 글로 간편취재는 보조 방식으로 유지

## 보존
- 기존 기자 인증/RLS 유지
- 기존 간편취재 유지
- AI 자동발행 없음
- 최종관리자 승인 발행 원칙 유지
- 가짜 운영 데이터 생성 없음
