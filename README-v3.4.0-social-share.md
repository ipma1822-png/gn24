## 추가 기능
- 본문 아래에 큰 `이 기사를 함께 나눠주세요` 공유 박스
- 기사 대표이미지 + 기사 제목을 공유 박스에 자동 표시
- 카카오톡 공유 버튼을 가장 크게 강조
- 링크 복사 / BAND / Facebook / X / Telegram / 시스템 공유
- 링크 복사 시 안내문 표시
- 모바일 화면 하단 고정 공유바
  - 카카오톡
  - 링크복사
  - 공유
- 기존 카카오 기사별 OG 정적 공유주소(`/share/기사ID/`) 사용
- 기존 조회수, 댓글, 반응, 기자 프로필, 많이 본 뉴스, 압축형 공식 푸터 유지
