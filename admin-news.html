자동 임시저장 + GitHub 반영 순서

  1. 기사 작성·수정 내용은 브라우저에 자동 임시저장됩니다. 새로고침해도 복원됩니다.
  2. 한 기사 편집을 마치면 현재 기사 저장을 눌러 편집본에 확정
  3. 상단의 news.json 내려받기
  4. 새 사진은 새로고침 후에도 자동 복원됩니다. 최종 반영 전에 이미지 파일 내려받기
  5. GitHub에서 data/news.json을 새 파일로 교체
  6. 사진은 assets/images/news/에 업로드

기사 상세페이지·최신뉴스·카테고리 영역은 news.json을 읽기 때문에 반영 후 자동으로 갱신됩니다.
