v3.2.6 온라인 편집국 사용 순서

  1. Supabase Authentication에서 관리자 계정을 만든 뒤 gn24_admins에 관리자 이메일을 등록합니다.
  2. 이메일로 관리자 로그인을 누르고 관리자 이메일을 입력합니다. Gmail로 도착한 로그인 링크를 누르면 비밀번호 없이 편집실로 돌아옵니다.
  3. Supabase 기사 불러오기를 누르면 DB의 현재 기사 전체를 관리자 편집실 왼쪽 목록으로 가져옵니다.
  4. 기사 작성·수정 후 온라인 저장·발행을 누르면 DB에 즉시 저장됩니다. 새 대표사진이 있으면 news-images Storage에도 함께 올라갑니다.
  5. 공개 체크를 해제하고 저장하면 비공개 상태로 저장됩니다.
  6. 온라인 삭제는 Supabase DB의 현재 기사만 삭제하며, 기존 GitHub의 news.json 원본은 건드리지 않습니다.

안전장치: 기존 Local Storage/IndexedDB 임시저장과 news.json 내려받기 기능은 계속 유지됩니다.
