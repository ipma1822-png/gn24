# GLOBAL NEWS24 기사 이미지 자동 최적화 시스템

목표: 기사/기자 업로드 이미지를 Supabase Storage 저장 전에 브라우저에서 자동 최적화하여 무료 Storage 사용량을 크게 줄인다.

기본 정책:
- 기사 이미지: 긴 변 최대 1600px
- WebP 우선 변환
- 품질 0.80~0.82
- EXIF/불필요 메타데이터 제거(브라우저 재인코딩)
- 작은 이미지는 불필요한 확대 금지
- 최적화 실패 시 원본 업로드로 안전하게 fallback
- 기존 기사/URL/DB/Supabase 구조 유지
- 기자 제보 이미지에도 같은 공통 유틸리티 적용 가능하게 설계

예상 효과: 현재 평균 약 2.28MB/장인 이미지를 일반적으로 수백 KB 수준으로 낮춰 Storage 수명을 수배 이상 연장.
