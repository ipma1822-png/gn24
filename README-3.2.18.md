# Global News24 v3.2.18 댓글 관리자

1. Supabase SQL Editor에서 `SUPABASE-COMMENT-ADMIN-v3.2.18.sql` 전체 실행
2. GitHub에 아래 4개 파일을 같은 경로로 덮어쓰기
   - admin-news.html
   - assets/css/admin-news.css
   - assets/js/news-admin.js
   - assets/js/news-cms.js
3. 관리자 편집실 Ctrl+F5
4. 로그인 상태에서 상단 `💬 댓글 관리` 클릭
5. 승인대기 / 공개 / 숨김 탭에서 댓글 관리

기능
- 승인대기 숫자 배지
- 기사 제목, 닉네임, 작성시각, 댓글 내용 확인
- 승인·공개
- 숨김
- 완전 삭제
- 해당 기사 새 창 확인
- 기사 작성/저장/이미지/Supabase 기존 CMS 기능 유지
