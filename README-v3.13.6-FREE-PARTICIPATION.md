# GLOBAL NEWS24 v3.13.6 — 무료 참여기자 체계

## PHASE 7-7
정식 기자와 별도로 시민기자·청소년기자·어린이기자의 무료 참여 흐름을 구축했다.

### 공개 흐름
1. `/pages/participant-apply/` 무료 신청
2. 본사 심사
3. 승인 시 활동번호 자동 발급
   - 시민기자: `GN24-CIT-YYYY-00001`
   - 청소년기자: `GN24-YTH-YYYY-00001`
   - 어린이기자: `GN24-JNR-YYYY-00001`
4. `/pages/participant-submit/`에서 승인 활동번호로 제보
5. 본사 검토 후 채택·기사화 여부 결정

### 본사 관리
- `/pages/admin-participation/`
- 신청자 유형·지역·보호자동의·상태·활동번호·본사 메모 관리
- 무료 참여 제보의 접수·검토중·추가확인·채택·기사화·반려 상태 관리
- 승인과 상태변경은 본사 최종관리자 권한으로 제한

### 데이터
- 기존 `gn24_participation_applications`에 `activity_number`, `approved_at`, `reviewed_by` 추가
- 신규 `gn24_participant_submissions` 생성
- 활동번호가 없는 제보는 FK로 차단
- 활동번호는 식별번호이며 로그인 비밀번호나 신분인증 수단이 아니다.

### 미성년 보호
- 청소년기자·어린이기자는 보호자 성명·연락처·동의가 있어야 공개 신청 RLS를 통과한다.
- 무료 참여자는 정식 기자 직급·기자증·편집권을 자동으로 얻지 않는다.

### 보안·호환성
- 기존 `gn24_reporters`, 기자 로그인, 기자번호, AI NEWSROOM, 기사발행 권한을 변경하지 않았다.
- 공개 사용자는 신청 및 제보 INSERT만 가능하다.
- 신청/제보 전체 조회 및 변경은 기존 본사 권한체계를 따른다.
- 서비스 역할/비밀키를 프론트엔드에 추가하지 않았다.
