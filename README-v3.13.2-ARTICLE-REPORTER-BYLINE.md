# GLOBAL NEWS24 v3.13.2 — PHASE 7-3 기사 기자 직급·본부 자동표시

## 완료 내용
- `gn24_public_reporters()` 공개 기자 조회 RPC에 기자 직급, 기자 종류, 조직 직책, 시·도본부, 특별지정 필드를 추가했다.
- 함수는 `security invoker`를 유지하며 활성 기자만 반환한다.
- 공개 기사 화면에서 기사 `reporter_id`를 기준으로 기자 정보를 조회한다.
- 기사 상단 바이라인과 기자 프로필 카드에 현재 기자 직급과 시·도본부를 자동 표시한다.
- `reporter_id`가 없는 기존 기사·편집부 기사는 기존 `author` 값을 그대로 사용한다.
- 수석기자 또는 시·도본부장 직책은 시스템 `admin/editor` 권한과 연결하지 않는다.

## 기사 표시 예시
- `김철수 수석기자 | 부산본부`
- 기자 카드: `전문기자 · 부산본부장 · 부산본부 · Global News24`

## 회귀 보호
- 기사 본문, 갤러리, 조회수, 댓글, SNS 공유, AI NEWSROOM, 기자증 기능은 변경하지 않았다.
- 기존 `article-gallery.js`의 갤러리 기능을 유지한 상태에서 기자 신분 표시 보조 로직만 추가했다.

## Supabase 검증
- `gn24_public_reporters()`가 신규 조직 필드를 정상 반환하는 것을 확인했다.
- `anon` 역할의 RPC 실행 권한과 신규 공개 필드 SELECT 권한을 확인했다.
- 보안 Advisor에서 이번 RPC는 SECURITY DEFINER 경고 대상이 아니며 기존 별도 경고들만 확인됐다.
