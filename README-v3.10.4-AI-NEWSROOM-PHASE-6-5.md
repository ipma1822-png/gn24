# GLOBAL NEWS24 AI NEWSROOM — PHASE 6-5
Version: v3.10.4

## 목적
PHASE 6의 기자 관리·네트워크 기능을 하나의 본사 운영 흐름으로 통합한다.

## 완료
- `/pages/admin-reporter-operations/` 기자 운영 통합센터 추가
- 기자 모집 → 지원서 심사 → 기자 네트워크 → 지역·전문 취재망 → 기자 모바일센터 → AI 편집·최종발행 순서로 연결
- 운영센터에서 지원서/등록기자/취재제출/공개기사 수를 현재 Supabase 데이터로 표시
- 기존 기자 네트워크 대시보드에 기자 운영센터 링크 추가
- 관리자와 편집자 권한을 구분해 표시
- 기자 임명·활동정지·권한변경과 최종 공개발행은 기존 관리자 전용 원칙 유지

## 회귀 점검
- 기존 `gn24_reporters`, `gn24_reporter_applications`, `gn24_reporter_submissions`, `gn24_articles` 구조 변경 없음
- 기존 공개 기사/기자 데이터 삭제 또는 자동 수정 없음
- 테스트용 기자·지원서·취재자료 생성 없음
- PHASE 6-4에서 확인한 초기 데이터 형식 불일치(region 복합문자열, specialties 내 비전문분야 값)는 자동 보정하지 않음

## PHASE 6 완료 범위
1. 기자 운영 대시보드
2. 기자 프로필·활동 상세
3. 관리자 전용 임명/정지/복구/권한변경
4. 지역·전문분야 취재망 분석
5. 기자 운영 통합센터

## 다음
PHASE 7 — 손안의 마법사 연동. 기자가 휴대폰에서 말하고, 사진을 올리고, 간단한 취재내용을 보내면 본사 AI NEWSROOM으로 이어지는 현장형 기자 카드/빠른 취재 흐름을 구축한다.
