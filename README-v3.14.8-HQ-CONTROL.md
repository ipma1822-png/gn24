# GLOBAL NEWS24 v3.14.8 — HQ CONTROL

본사 관리자용 통합 관제 허브.

## 목적
기존에 구축된 기자, 수습기자, 시·도본부, 시·군·구 지부, 본사 운영조직, 운영분담금, 지역 기자추천 심사, MY GN24, 정책 안내 AI, 공식 정책센터를 한 화면에서 연결한다.

## 보안 원칙
- HQ CONTROL 자체는 `is_gn24_admin()`으로 본사 관리자 여부를 확인한다.
- 각 업무 화면의 기존 RLS 및 관리자 검증을 우회하지 않는다.
- noindex/nofollow는 검색노출 방지일 뿐 보안수단으로 간주하지 않는다.
- 운영분담금, 조직직책, 기자직급과 편집권/관리자권한은 별개다.
