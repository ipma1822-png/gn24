# Global News24 v3.3.0 — 메인페이지 자동 편집 강화

- TOP NEWS: 관리자 편집실의 `TOP NEWS 고정` 기사 우선
- 주요 뉴스: `주요뉴스` 체크 기사 우선, 부족하면 최신기사 자동 보충
- 속보: `표시 스타일 = 속보 강조` 기사 자동 노출
- 최신 뉴스: 공개 기사 등록일/생성일 기준 자동 정렬
- 많이 본 뉴스: `gn24_article_views` 실제 조회수 TOP10 자동 반영, 데이터가 없으면 최신기사로 안전 대체
- 주목 뉴스: 주요뉴스 우선 자동 구성
- 무도·스포츠 / 안전·드론 / 공익: 기사 카테고리·키워드 기준 자동 구성

기존 Supabase 기사, 댓글, 공감, 조회수, 기사 상세, OG 공유 자동화 구조는 유지합니다.
