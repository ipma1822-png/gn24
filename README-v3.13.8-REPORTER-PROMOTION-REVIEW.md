# GLOBAL NEWS24 v3.13.8 — 기자 승급·실적 심사센터

## PHASE 7-9

정식 기자의 실적을 자동 집계하고 본사에서 승급을 최종 결정하는 체계를 구축했다.

### 자동 집계 항목
- 활동기간: `appointed_at` 우선, 없으면 `created_at`
- 공개기사 수: `gn24_articles.reporter_id` 연결 + `is_published=true`
- 취재제출 수: `gn24_reporter_submissions` 중 제출된 기록
- AI 편집점수 평균: `ai_edit_score`가 있는 경우 참고값
- 주의기록: 정지·해촉 등 중대한 인사 불이익 기록

### 초기 후보 기준
- 기자 → 선임기자: 활동 1년+, 공개기사 50건+, 취재제출 20건+, 중대한 주의기록 0건
- 선임기자 → 수석기자: 활동 3년+, 공개기사 200건+, 취재제출 80건+, 중대한 주의기록 0건

이 수치는 자동승급 기준이 아니라 본사 승급심사를 시작하기 위한 후보 기준이다. 기사품질, 대표기획, 윤리, 조직기여 등 정성평가는 본사가 별도로 판단한다.

### 권한 원칙
- 관리자와 편집자는 실적·후보 현황 조회 가능
- 최종 승급 실행은 `is_gn24_admin()`을 통과한 본사 최종관리자만 가능
- 승급은 한 단계씩만 허용
- 기자 → 수석기자 직접 승급 불가
- 승급 시 `gn24_reporter_personnel_audit`에 `promotion` 기록 자동 저장
- 기자 직급과 `access_level`은 계속 분리되며 승급으로 시스템 관리자/편집자 권한이 생기지 않음

### 화면
- `/pages/admin-reporter-promotions/`
- 기자 운영 통합센터에서 바로 진입 가능

### DB 함수
- `gn24_admin_promotion_metrics()` — 실시간 실적 집계 및 후보 판정
- `gn24_admin_apply_promotion(...)` — 본사 최종승급 + 인사기록 원자적 처리

두 함수 모두 `SECURITY INVOKER`이며 익명 실행권한을 부여하지 않았다.

### 보호한 기존 기능
정식 기자 로그인, 기자증, 기자센터, AI NEWSROOM, 기사 `reporter_id`, 지역본부, 운영분담금, 무료 참여기자 시스템은 변경하지 않았다.
