## v3.1.12 핵심 변경
- 기사 글 자동 임시저장 기능 유지
- 새로 선택한 대표이미지를 브라우저 IndexedDB에 Blob 형태로 임시저장
- 새로고침 후에도 선택했던 새 이미지 미리보기 자동 복원
- 기사별 임시이미지 분리 저장
- `새 이미지 임시저장됨` 상태 안내
- `임시 이미지 취소` 버튼 추가
- 임시편집본 초기화 시 글 임시저장과 이미지 임시저장을 함께 삭제
- 기존 v3.1.11 Local Storage 편집본을 그대로 이어서 사용할 수 있도록 저장 키 호환 유지

## 중요
IndexedDB의 이미지 임시저장은 현재 브라우저의 작업 보존용입니다. 실제 홈페이지에 반영하려면 최종적으로 `news.json 내려받기`와 `이미지 파일 내려받기`를 한 뒤 GitHub의 `data/news.json` 및 `assets/images/news/`에 업로드해야 합니다.

1. 관리자 페이지에서 기사 선택

4. 새로고침
