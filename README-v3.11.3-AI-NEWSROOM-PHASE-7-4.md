# GLOBAL NEWS24 AI NEWSROOM — PHASE 7-4
Version: v3.11.3

## 목표
기자가 휴대폰에서 자신이 보낸 취재 원문과 AI 기사 초안을 확인할 수 있도록 손안의 마법사 흐름을 연결한다.

## 완료
- 기자 상태 화면을 `내 취재 → AI 기사 확인` 중심으로 업그레이드
- 기자 본인 제출건에서 AI 기사 초안 생성 버튼 제공
- 기존 Edge Function `gn24-draft-article` 호출
- AI 제목, 부제, 리드, 본문, 키워드, 추가확인 사실 표시
- `내가 보낸 내용`과 `AI 기사 초안`을 좌우 비교 표시
- 모바일에서는 상하 비교로 자동 전환
- AI 초안은 자동 발행이 아님을 화면에 명시
- 손안의 마법사 메뉴에서 AI 기사 확인으로 직접 진입

## 보존
- 기자 본인 자료만 RLS로 조회
- 기존 최종관리자 승인 발행 원칙 유지
- 기존 편집데스크 및 최종발행 로직 유지
- 운영 데이터 수정/가짜 제출 생성 없음

## 서버 의존성
`gn24-draft-article`는 Supabase Edge Function에서 `OPENAI_API_KEY`가 설정되어 있어야 실제 AI 초안을 생성한다. 키가 없으면 기자 화면에서 본사 설정 필요 안내만 표시하며 비밀키를 브라우저나 GitHub에 노출하지 않는다.
