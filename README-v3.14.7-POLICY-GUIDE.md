# GLOBAL NEWS24 v3.14.7 — 정책 안내 AI

## 목적
공식 5년 운영정책 v1.0과 현행 시스템 운영기준을 근거로 기자제도, 지역조직, 본사 운영직책, 운영분담금, 편집권 질문에 대해 정책 문답 검색 결과를 제공한다.

## 구현
- `/pages/policy-search/`
- `/assets/js/policy-search.js`
- `/assets/data/gn24-policy-qa-v1.0.json`

## 원칙
- 생성형 자유답변이 아니라 공식 문답 검색 방식으로 운영한다.
- 정책에 없는 내용은 추정하거나 임의 결정하지 않는다.
- 질문과 가장 가까운 정책 문답을 점수화해 표시한다.
- 근거 조항 또는 현행 시스템 운영기준을 함께 표시한다.
- 운영분담금 상태는 현행 시스템 기준 `정상 / 미납 / 유예 / 면제` 4개 상태로 안내한다.
- 직책, 분담금, 편집권, 관리자권한은 서로 분리한다.
