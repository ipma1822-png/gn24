# GLOBAL NEWS24 v3.13.1 — REPORTER ORGANIZATION CONTROL

## PHASE 7-2

본사 최종관리자 기자 상세화면에 다음 조직관리 항목을 추가했다.

- 기자 직급: 기자 / 선임기자 / 수석기자
- 기자 종류: 일반기자 / 지역기자 / 전문기자 / 객원기자 / 해외통신원 / 시민기자 / 청소년기자 / 어린이기자
- 조직 직책: 편집국장 / 취재부장 / 시·도본부장 / 지부장
- 17개 시·도본부 코드
- 특별지정: 특임기자, 논설위원 등 복수 입력
- 최근 승급일 자동 기록
- 기존 인사감사 테이블에 조직정보 변경 이력 기록

## 권한 원칙

기자 직급과 시스템 권한은 분리한다. 수석기자 또는 시·도본부장이라고 해서 editor/admin 권한이 자동 부여되지 않는다. 최종 변경은 기존 is_gn24_admin() 권한을 가진 본사 관리자에게만 허용된다.

## 기존 기능 보호

기존 role, access_level, 로그인, 카카오 연결, 기자번호, 기자증, 기사 reporter_id, AI NEWSROOM, 활동정지·해촉 흐름은 유지했다.
