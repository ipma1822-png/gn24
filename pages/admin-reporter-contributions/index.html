운영분담금 통합관리

정식 기자·지부장·시·도본부장·본사 운영직책을 한 사람 기준으로 계산하여 월납 또는 연납을 관리합니다. 여러 직책을 동시에 보유하더라도 가장 높은 운영분담금 하나만 적용합니다.

예: 정식 기자 1만원 + 지부장 3만원 + 운영위원 2만원을 동시에 보유해도 월 3만원 하나만 적용합니다. 시·도본부장 5만원과 상임운영이사 10만원을 동시에 보유하면 월 10만원 기준만 적용합니다.
운영분담금 상태는 정상 / 미납 / 유예 / 면제 네 가지로만 관리합니다. 이는 기자 활동상태·징계상태와 별개입니다. 운영분담금 납부는 기자자격·직책·편집권·관리자권한을 구매하는 행위가 아닙니다.
