# GLOBAL NEWS24 AI NEWSROOM — PHASE 7-1
Version: v3.11.0

## 완료
- 기자 전용 `손안의 마법사` 모바일 허브 추가
- 기자센터에 가장 눈에 띄는 진입 CTA 추가
- 기존 기자 인증 세션 재사용
- 비로그인 상태에서 기자센터 로그인으로 이동 후 다시 손안의 마법사로 복귀
- 활동 기자만 사용 가능
- 말로 취재하기 / 간단히 적어 보내기 / 내 기자증 / 본사 진행상태 보기 연결
- 자동발행 금지 및 사실 기반 취재 원칙 표시

## 보안·운영 원칙
- 새로운 공개 권한이나 DB 권한을 추가하지 않았다.
- 기존 `gn24_my_reporter_id` 및 기자 RLS를 그대로 사용한다.
- 기자가 보내는 내용은 기존 `gn24_reporter_submissions` 흐름을 사용한다.
- AI가 기사를 생성해도 최종 관리자 승인 전에는 공개되지 않는다.

## 현재 제한
- 직접 사진 파일 업로드는 아직 연결하지 않았다. 기존 간편취재의 media URL 입력 방식만 유지한다.
- 브라우저 음성인식 지원 여부에 따라 음성 취재는 수동 입력으로 대체될 수 있다.
- 로그인 토큰 자동 갱신은 추후 통합 보강 대상이다.
