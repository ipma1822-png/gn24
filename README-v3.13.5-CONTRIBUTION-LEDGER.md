# GLOBAL NEWS24 v3.13.5 — PHASE 7-6 운영분담금 관리대장

## 목적
정식 기자와 시·도본부장의 월별 운영분담금을 카드·간편결제 없이 지정계좌 입금 확인 방식으로 본사에서 관리한다.

## 핵심 구조
- `gn24_contribution_rules`: 본사 운영 기준금액
  - 정식 기자: 월 10,000원 기본값
  - 시·도본부장: 월 50,000원 기본값, 일반 기자분담금과 중복 부과하지 않음
  - 객원기자/해외통신원: 초기 기본 면제
- `gn24_contributions`: 기자별·월별 실제 관리대장
  - 상태: `paid / unpaid / deferred / exempt`
  - 화면표시: 정상 / 미납 / 유예 / 면제
  - 입금일, 실제금액, 메모 기록

## 운영 원칙
- 운영분담금은 기자 자격을 구매하는 비용이 아니다.
- 기자 위촉·직급·본부장 임명과 운영분담금은 별도 체계다.
- 본부장은 일반 기자분담금과 중복 부과하지 않는다.
- 월별 대장은 본사 관리자가 해당 월에 생성할 때만 만들어진다. 과거 월 자동청구 없음.
- 카드·간편결제·자동 온라인 결제 기능은 구현하지 않는다.

## 권한
- 익명 사용자는 접근 불가.
- 본사 최종관리자만 전체 조회·생성·수정·삭제 가능.
- 로그인 기자는 RLS에 의해 자신의 월별 기록만 읽을 수 있도록 기반을 마련했다.
- 기자 직급·본부장 직책이 시스템 `admin/editor` 권한을 자동 부여하지 않는다.

## 화면
