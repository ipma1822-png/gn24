# GLOBAL NEWS24 AI NEWSROOM — PHASE 6-4
Version: v3.10.3

## 완료
- 관리자/편집자 전용 지역·전문분야 기자 네트워크 화면 추가
- 활동 기자 기준 지역별 배치 집계
- 전문분야별 배치 집계
- 기자 역할/권한 구성 집계
- 지역/전문분야 미등록 및 초기 취재망 공백 경고
- 기존 기자 네트워크 대시보드에서 진입 링크 추가

## 원칙
- 기존 gn24_reporters 자료를 읽기 전용으로 집계한다.
- PHASE 6-4에서 기자 자료를 자동 수정하지 않는다.
- 편집자는 조회 가능하나 기자 상태/권한 변경은 기존 관리자 전용 규칙을 유지한다.
- 단순 인원수가 적다는 이유만으로 특정 지역/분야가 실제로 부족하다고 단정하지 않고 운영 검토 경고로 표시한다.

## 데이터 품질 메모
현재 일부 기존 기자 데이터는 region 또는 specialties 필드가 복합 문자열/이메일 등 초기 데이터 형식으로 저장되어 있어, 네트워크 화면은 저장된 값을 그대로 집계한다. 향후 프로필 정규화 단계에서 관리자 확인 후 정리하는 것이 안전하다.
