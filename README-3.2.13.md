- 현재 기사와 연관도가 높은 관련뉴스 최대 4건 자동 표시
- Global News24 홈/전체기사 바로가기 박스 추가
- 사이드바는 PC에서만 표시하고 모바일/태블릿에서는 기존 1단 기사 화면 유지
- 기사 DB, Supabase, 관리자 편집실, 기존 기사 본문은 변경하지 않음
