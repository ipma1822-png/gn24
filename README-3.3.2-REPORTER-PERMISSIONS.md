# Global News24 v3.3.2 · 기자 권한 시스템

기존 v3.3.1 기능을 유지하면서 기자 관리에 `권한`과 `로그인 이메일`을 추가했습니다.

- 편집국(editor): 전체 기사 관리·발행
- 정식기자(reporter): 자기 기사 작성·수정, 발행은 편집국 승인
- 객원기자(contributor): 자기 기사 작성 후 승인대기
- 활동/승인대기/활동정지는 기존 기자 상태로 별도 유지

## 적용 순서
1. 이 ZIP의 파일을 GitHub 저장소 기존 위치에 덮어씁니다.
2. Supabase SQL Editor에서 `SUPABASE-UPGRADE-v3.3.2-REPORTER-PERMISSIONS.sql`을 한 번 실행합니다.
3. 관리자 편집실 → 기자 관리에서 각 기자의 권한과 로그인 이메일을 저장합니다.

이번 단계는 안전한 권한 데이터 구조와 RLS 기반을 먼저 구축한 버전입니다. 기존 관리자 로그인과 기사 발행 기능은 그대로 유지합니다.
