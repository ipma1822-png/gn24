# GLOBAL NEWS24 v3.13.4

## PHASE 7-5 · 17개 시·도본부 공식 관리시스템

### 완료 내용
- `gn24_regional_headquarters` 신설
- 서울·부산·대구·인천·광주·대전·울산·세종·경기·강원·충북·충남·전북·전남·경북·경남·제주 17개 본부 기본 데이터 생성
- 본부장 기자 ID, 본부 상태, 임명시각, 임기 시작/종료, 월 운영분담금 기준, 본사 메모 관리
- 본부장 변경 시 해당 기자의 `organization_position=시·도본부장`, `regional_hq_code=본부코드` 동기화
- 전임 본부장 변경 시 기존 본부장 직책/본부 연결 해제
- 본사 최종관리자 전용 `/pages/admin-regional-headquarters/` 관리화면 추가
- 기자 운영 통합센터에서 17개 시·도본부 관리센터 진입 가능

### 권한 원칙
- 공개 익명 사용자는 본부 관리테이블 직접 접근 불가
- 로그인 사용자는 조회만 가능
- INSERT/UPDATE/DELETE는 `is_gn24_admin()`을 통과한 본사 최종관리자만 가능
- 본부장 직책은 시스템 `access_level`과 분리되어 있으며 본부장 임명만으로 editor/admin 권한이 생기지 않음

### 검증
- 17개 본부 데이터 생성 확인
- RLS 활성화 및 관리자 전용 쓰기 정책 적용
- Supabase Security Advisor 재검사 완료
- 기존 Advisor 경고는 이번 단계에서 새로 발생한 것이 아니며 별도 보안정비 단계에서 처리 예정
