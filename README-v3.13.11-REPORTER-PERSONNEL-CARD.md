# GLOBAL NEWS24 v3.13.11 — PHASE 7-11

## 기자 개인 인사카드·성과 리포트 시스템

이번 단계는 기자 한 명의 핵심 신원·조직·성과·인사기록을 본사에서 한 장으로 조회하는 통합 인사카드를 구축한다.

### 새 관리자 화면
- `/pages/admin-reporter-card/`
- URL 파라미터 `?id=기자ID`로 특정 기자를 바로 열 수 있다.
- 본사 관리자와 편집자가 조회할 수 있다.
- 조회 화면에서는 인사정보를 직접 변경하지 않는다.

### 한 장에서 확인하는 항목
- 기자명·사진·기자번호
- 기자 직급·기자 유형·조직 직책
- 17개 시·도본부 소속·특별지정
- 활동기간
- 누적 공개기사
- 취재제출 건수
- AI 편집점수
- 교육이수·본사포상·대표기획·경고·징계 건수
- 인사 참고점수
- 승급심사 판정
- 최근 공개기사 10건
- 최근 취재제출 10건
- 공식 인사기록 전체
- 승급 및 인사 변경 감사이력

### 기존 시스템과 역할 분리
개인 인사카드는 조회·판단용 화면이다.
- 직급 변경: `/pages/admin-reporter-promotions/`
- 교육·포상·대표기획·경고·징계 등록/취소: `/pages/admin-reporter-records/`
- 전체 운영: `/pages/admin-reporter-operations/`

최종 기자 인사권과 승급 결정권은 GLOBAL NEWS24 본사에 유지된다.

### 데이터 구조
PHASE 7-11은 새로운 테이블을 만들지 않는다. PHASE 7-10까지 구축된 다음 데이터를 읽어 통합한다.
- `gn24_reporters`
- `gn24_articles`
- `gn24_reporter_submissions`
- `gn24_reporter_records`
- `gn24_reporter_personnel_audit`
- `gn24_admin_promotion_metrics_v2()`

새로운 DB 쓰기 경로를 추가하지 않았으며, 기존 RLS와 권한구조를 그대로 사용한다.

### 연결 개선
- 기자 운영 통합센터에 `개인 인사카드` 진입점 추가
- 승급심사 표의 기자명을 누르면 해당 기자 개인 인사카드로 이동
- 인사기록센터에 개인 인사카드 링크 추가
- 개인 인사카드에서 선택한 기자를 인사기록센터로 넘길 때 `?reporter=`로 기자 선택값을 유지

### 보호 원칙
루트 `/index.html`은 수정하지 않았다. 메인 뉴스 홈페이지와 기자 시스템의 작업경로를 분리한다.
