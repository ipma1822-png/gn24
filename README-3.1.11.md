# Global News24 v3.1.11 — 관리자 편집실 자동 임시저장

기준 버전: v3.1.10

## 변경 내용
- 기사 작성·수정 내용을 브라우저 Local Storage에 자동 임시저장
- 새로고침/탭 재접속 후 마지막 편집 내용 자동 복원
- 현재 상태를 `원본 상태 / 임시저장됨 / 임시편집본 복원됨 / GitHub 반영 필요`로 구분 표시
- `임시편집본 초기화` 버튼 추가: 로컬 임시편집본 삭제 후 사이트 `data/news.json` 원본 재로드
- 현재 기사 저장/삭제/복제/news.json 불러오기 시 자동 임시저장
- 탭이 백그라운드로 이동할 때도 임시저장
- 새 이미지 선택 시 이미지 경로·파일명은 임시저장되지만 브라우저 보안상 이미지 파일 자체는 새로고침 후 자동 복원되지 않음을 안내
- 새 이미지 파일이 선택된 상태에서 페이지를 닫거나 새로고침할 때 브라우저 경고 유지

## GitHub 업로드 파일
이번 선별 ZIP의 아래 4개 파일만 기존 경로에 그대로 덮어쓰면 됩니다.

- `admin-news.html`
- `assets/js/news-admin.js`
- `assets/css/admin-news.css`
- `README-3.1.11.md`

기존 `data/news.json`, 기사 이미지, 메인 페이지, 기사 상세페이지는 변경하지 않습니다.

## 사용 흐름
1. `/admin-news.html` 접속
2. 기사 수정 또는 신규 작성 — 입력 중 자동 임시저장
3. 새로고침해도 마지막 편집 내용 자동 복원
4. 기사 단위 작업 완료 시 `현재 기사 저장`
5. 전체 작업 완료 시 `news.json 내려받기`
6. GitHub `data/news.json` 교체
7. 새 이미지가 있다면 해당 이미지 파일을 `assets/images/news/`에 업로드
8. GitHub 반영이 끝난 뒤 필요하면 `임시편집본 초기화`로 사이트 원본 상태 재로드
